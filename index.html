Cấu hình & Nguồn API Thời tiết

Hệ thống sẽ đối chiếu độc lập nhiệt độ từng ngày:
• Sinh hoạt: Mức nhạy cảm cao (~1.5%/°C)
• Kinh doanh: Mức nhạy cảm TB (~1.0%/°C)
• Sản xuất: Ít ảnh hưởng thời tiết (~0.2%/°C)
• Tháng T (Nền tảng): Lấy mảng cao nhất từng ngày tháng T.
• Tháng T+1: Khớp API khí hậu tháng T+1 chuẩn xác.
• Tháng T+2: Khớp API khí hậu tháng T+2 chuẩn xác.
